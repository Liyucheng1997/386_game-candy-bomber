# 糖豆炸弹人 3D

仿《泡泡堂》玩法的 3D 炸弹人小游戏，基于 Three.js。模型全部用代码生成，没有外部美术资源。

## 运行

双击 `start.bat`，或者：

```bash
npm install
npm run dev -- --port 5386
```

然后用浏览器打开 http://localhost:5386 。

## 玩法

- 放泡泡：泡泡会沿十字方向喷出水柱，打碎糖果方块并掉出道具
- 被水柱击中的角色会被**困在泡泡里**。对手碰到就戳破（出局），队友碰到就救出
- 持有**救命针**时可以自己脱困
- 时间耗尽进入**加时赛**：糖块从天而降，场地越缩越小
- 模式：个人混战（1~2 名玩家 + 电脑）、2v2 团队（单人或双人合作打电脑）
- 3 张地图：糖果小镇 / 饼干花园 / 冰淇淋广场，可以选轮换

| 操作 | 1P | 2P |
| --- | --- | --- |
| 移动 | W A S D | 方向键 |
| 放泡泡 | 空格 | Enter |
| 救命针 | E | 右 Shift |

单人模式下方向键和 Enter 也能操作 1P。支持手柄（A 放泡泡，B 用针）。Esc 暂停。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/main.js` | 渲染器、后期辉光、相机、菜单 |
| `src/game.js` | 核心玩法：网格、泡泡、水柱、道具、困泡泡、加时、回合 |
| `src/ai.js` | 电脑 AI：危险地图 + BFS 寻路 + 评分决策 |
| `src/models.js` | 程序化建模：糖豆人、泡泡、方块、道具、装饰 |
| `src/world.js` | 天空、灯光、蛋糕平台、围栏、周边装饰 |
| `src/audio.js` | WebAudio 合成的音效和背景音乐 |
| `src/particles.js` | 实例化粒子特效 |
| `src/constants.js` | 数值、角色、道具、地图配置 |
